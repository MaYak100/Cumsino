# Предметы, бонусы, блайнды

Константы и цены — `shared/src/items.ts`, типы и события — `shared/src/types.ts`. Всё, что даёт деньги сверх пула
(молния, серия, BKB, аегис), платит казино.

## Лавка (фаза SHOP)

- Лавка открывается **перед каждым раундом «для всех»**: перед первым раундом (сразу после «Начать») и после итогов
  каждого раунда «кто ближе» (цикл all → kerri → closest). Раунд «для всех»: SHOP → ANNOUNCE → BETTING → QUESTION → REVEAL.
  Перед керри и «кто ближе» лавки нет.
- Лавка — уже часть следующего раунда: `nextRound()` выбирает режим и вопрос, увеличивает `roundIndex` и сбрасывает
  раундовое состояние до лавки, поэтому купленное в лавке не стирается. В лавке `mode = 'all'`, `roundIndex` —
  номер следующего раунда, `currentQuestion = null` (вопрос выбран, но тема — сюрприз анонса; в ANNOUNCE он появляется).
- Длительность `PHASE_DURATIONS.SHOP` (25 с). `shop_ready {ready}` → `Player.shopReady` (публичное, только в фазе
  SHOP). Все игроки комнаты готовы — лавка закрывается сразу (→ ANNOUNCE). Ушёл последний неготовый — тоже. «Готов»
  можно снять. Вне лавки `shop_ready` игнорируется. На входе в лавку у всех `shopReady = false`, после — поле пропадает.
- Вошедший в лавке — полноценный участник раунда: может покупать, его «Готов» ждут.
- Победа проверяется в конце REVEAL, до лавки: GAME_OVER в лавке не бывает.

## Блайнды («для всех» и толпа керри)

- На входе в BETTING каждому, кто ставит, назначается минимальная ставка `blindFor(chips, big)`: 5% баланса,
  у лидера по балансу (большой блайнд) — 10%; вверх до $10, не меньше $10, не больше баланса. С балансом < $10 —
  блайнд 0 (может подтвердить и ставку 0; досрочный конец BETTING его не ждёт — фишек нет, подтверждать нечего).
- Большой блайнд — только у единственного лидера по балансу среди ставящих; лидеров несколько (ничья наверху) — у
  всех малый.
- **Керри:** блайнд у толпы, у керри нет (не ставит). Керри выбирается до назначения блайндов (ANNOUNCE → BETTING),
  лидер для большого блайнда — среди толпы (самый богатый может оказаться керри — он не в счёт; единственный в толпе
  — лидер). Сторону («ответит» / «завалит») выбирает игрок, но ставка обязательна. Банк-ставка — по желанию.
- `placeBet` со ставкой меньше блайнда отклоняется (если баланса на блайнд хватает); в керри ненулевая ставка без
  стороны (`target`) тоже отклоняется.
- Кто не подтвердил ставку к концу BETTING — ставка принудительно = блайнд (`betChips` нет, клиент разложит сумму),
  рассылается `bet_updated {playerId, amount}`. В керри — на **случайную сторону**: `bet_updated {playerId, amount,
  target}`; если толпа успела сделать банк-ставку без подтверждения — блайнд не больше остатка баланса.
- «Кто ближе» — без блайндов. Зрителям (см. «Вошёл посреди раунда») блайнд не назначается.

## Бонусы

- **Молния.** Верный ответ, отправленный в первые `LIGHTNING_MS` (5 с) фазы QUESTION: «для всех» — `round10(ставка ×
  LIGHTNING_SHARE)` (не меньше $10 — в том числе безденежному со ставкой 0), керри — `LIGHTNING_GLADIATOR` ($100).
  Толпе керри и в «кто ближе» молнии нет. Время ответа — последнего (после блинка — новое). Источник «Молния».
- **Серия** (`streak` в Player, видна всем). По итогам раунда:
  - «для всех»: верно → +1; неверно или не ответил → 0;
  - керри: керри верно → +1, иначе (в том числе не ответил) 0; толпа: угадал исход основной ставки → +1, ошибся → 0
    (пропустить ставку нельзя — блайнд принудительный; без ставки остаётся только безденежный с блайндом 0 — у него
    серия без изменений; банк-ставка на серию не влияет);
  - «кто ближе» серию **не сбивает**: ближайший → +1, все остальные (в том числе не ответившие) — без изменений.
  - Под активным BKB серия не сбивается (но и не растёт при проигрыше).
  - Бонус при серии ≥ 2 (уже с учётом этого раунда): `round10(база × streakShare(серия))`; база — ставка («для всех»),
    основная ставка (толпа керри), `STREAK_GLADIATOR_BASE` (керри), `CLOSEST_WINNER_BONUS` (кто ближе).
    Источник «Серия ×N».

Порядок начисления после основного расчёта: молния → серия → BKB → аегис. Отменённый раунд («Керри сбежал») не
считается вовсе: ни бонусов, ни BKB, ни аегиса.

## Предметы

Запас у каждого свой (`inventory`, только себе в `getStateForPlayer`), вместе с ценами (`prices`) и `aegisBought`.
Чужой запас никто не видит; применение видно (событие `item_used`, эффекты в `Player.effects`).

**Покупка** — `buy_item {item}`, только в лавке (`BUY_PHASES = ['SHOP']`). Цена `itemPrice(item, chips)` — списывается
сразу; купить можно ровно на весь баланс. С балансом от $3000 покупать нельзя (страховка). Нельзя больше `max` в
запасе; аегис — один за игру (`aegisBought`), сразу становится активным (эффект `aegis`, не лежит в запасе).
Аегис нельзя купить, если после покупки баланс будет ниже `AEGIS_THRESHOLD`, и пока аегис активен, никакая покупка
не может опустить баланс ниже порога — иначе «купи аегис на последние деньги» = гарантированные $300 после раунда.

**Применение** — `use_item {item, targetId?}`, в `usePhases` предмета и в его `modes`; не хватает в запасе / не та
фаза / не тот режим / зритель / цель не подходит (сам, ушёл, зритель, нет цели) — молча игнор, предмет не тратится.
Списывается 1 шт. После расчёта раунда (окно показа ответа) ничего не применяется.

**Керри:** керри (отвечающий) может только **блинк**; толпа — только **BKB**. В анонсе керри ещё не выбран — все
считаются толпой; BKB, включённый будущим керри в анонсе, возвращается ему в запас при выборе керри.

| Предмет | Когда | Действие |
|---|---|---|
| **Blink** | QUESTION; all, closest, керри (только сам керри) | Не через use_item: `submit_answer {answer, blink: true}` при уже отправленном ответе меняет ответ (на другой — тот же не тратит) и тратит блинк. Первый ответ с флагом — обычный ответ. Всем `item_used` (если не в смоке). |
| **Gem** | QUESTION, all / closest; цель — другой участник | Смотрящему — `gem_result {targetId, answer (текущий выбор: вариант или число; null — ещё не ответил), smoked}`. Всем — `item_used` без цели (если смотрящий не в смоке); цели — `item_used {onYou: true}`. Цель в смоке: `answer: null, smoked: true`. Смотрящий в смоке — о геме не знает никто, включая цель. |
| **Manta** | QUESTION, только all; раз за раунд | Убирает случайный неверный вариант (из ещё не убранных): себе — `manta_result {optionIndex}`, в стейт — `removedOptions`; ответ и блинк убранным вариантом отклоняются. Всем `item_used` (если не в смоке). |
| **Smoke** | BETTING / QUESTION, all / closest; раз за раунд | До конца раунда: твои блинк / гем / манта не рассылаются; гем на тебя — `smoked`. Включён до ответа — другим твой `hasAnswered` = false и `player_answered` только тебе; включён после ответа — ответ уже все видели, `hasAnswered` остаётся true. Сервер «все ответили» считает по настоящим ответам. Само применение видно всем (эффект `smoke`). |
| **Hex** | BETTING, all; цель — другой участник; один бросок на бросающего и одна порча на цель за раунд | Ставку бросающему делать не обязательно. У цели в QUESTION только `HEX_SECONDS` (12 с): позже ответы и блинки не принимаются; по истечении цель считается «ответившей» (без ответа) для досрочного конца фазы. Цель ушла — раунд считается по остальным. Цели — `hexTimeLeft` в её стейте. Всем `item_used {targetId}`, у цели эффект `hex`. |
| **BKB** | ANNOUNCE / BETTING, all / керри (только толпа); раз за раунд | При включении запоминается сейв `bkbCap(баланс)` = 2 × цена BKB на этот момент ($400 при базовой). Если раунд для игрока в минусе (у толпы керри — основная ставка + банк-ставка вместе) — возврат `min(потеря, сейв)`, источник «BKB». Серия не сбивается. Эффект `bkb`. |
| **Aegis** | пассивный, один на игру, все режимы | После расчёта раунда баланс < `AEGIS_THRESHOLD` → становится `AEGIS_RESTORE`, источник «Аегис», эффект снимается. Считается после BKB: если BKB вытянул выше порога, аегис остаётся. |

## Вошёл посреди раунда

Новый игрок (и переподключение — это новый сокет) приходит с `STARTING_CHIPS`, пустым запасом и серией 0. Вошёл в
лобби или в лавке — участник. Вошёл в ANNOUNCE…REVEAL — **зритель до следующего раунда** (`spectator`, только на
сервере): не ставит, не отвечает, не применяет предметы, не бывает целью гема/хекса, не становится керри, без блайнда;
досрочный конец BETTING / QUESTION его не ждёт. В итогах раунда — с нулём. `nextRound()` снимает флаг.

## Конец вопроса

Все ответили — раунд считается не сразу, а через `LAST_ANSWER_GRACE_MS` (1 с); блинк в это окно перезапускает
отсчёт. «Все ответили» учитывает хекс (у цели после 12 с — как ответ), смок (по настоящим ответам) и зрителей
(не ждутся).
