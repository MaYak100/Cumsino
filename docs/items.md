# Предметы, бонусы, блайнды

Константы и цены — `shared/src/items.ts`, типы и события — `shared/src/types.ts`. Всё, что даёт деньги сверх пула
(молния, серия, BKB, аегис), платит казино.

## Блайнды (только «для всех»)

- На входе в BETTING каждому игроку с балансом ≥ $10 назначается минимальная ставка `blindFor(chips, big)`:
  5% баланса, у ведущего (большой блайнд) — 10%; вверх до $10, не меньше $10, не больше баланса.
- Ведущий меняется по кругу: каждый раунд «для всех» — следующий игрок в порядке входа (`bigBlind` в Player).
- `placeBet` со ставкой меньше блайнда отклоняется (если баланса на блайнд хватает).
- Кто не подтвердил ставку к концу BETTING — ставка принудительно = блайнд (`betChips` нет, клиент разложит сумму),
  рассылается `bet_updated`.
- Керри и «кто ближе» — без блайндов.

## Бонусы

- **Молния.** Верный ответ, отправленный в первые `LIGHTNING_MS` (3 с) фазы QUESTION: «для всех» — `round10(ставка ×
  LIGHTNING_SHARE)` (не меньше $10), керри — `LIGHTNING_GLADIATOR`. Время ответа — последнего (после блинка — новое).
  Источник «Молния».
- **Серия** (`streak` в Player, видна всем). По итогам раунда:
  - «для всех»: верно → +1; неверно или не ответил → 0;
  - керри: керри верно → +1, иначе 0; толпа: угадал исход основной ставки → +1, ошибся или не ставил → 0;
  - «кто ближе»: ближайший → +1, не ответил → 0, остальные — без изменений.
  - Под активным BKB серия не сбивается (но и не растёт при проигрыше).
  - Бонус при серии ≥ 2 (уже с учётом этого раунда): `round10(база × streakShare(серия))`; база — ставка («для всех»),
    основная ставка (толпа керри), `STREAK_GLADIATOR_BASE` (керри), `CLOSEST_WINNER_BONUS` (кто ближе).
    Источник «Серия ×N».

Порядок начисления после основного расчёта: молния → серия → BKB → аегис.

## Предметы

Запас у каждого свой (`inventory`, только себе в `getStateForPlayer`), вместе с ценами (`prices`) и `aegisBought`.
Чужой запас никто не видит; применение видно (событие `item_used`, эффекты в `Player.effects`).

**Покупка** — `buy_item {item}`, только в фазах `BUY_PHASES` (REVEAL, ANNOUNCE). Цена `itemPrice(item, chips)` —
списывается сразу. С балансом от $3000 покупать нельзя (иначе покупка на итогах отнимает победу). Нельзя больше `max` в запасе; аегис — один за игру (`aegisBought`), сразу становится активным
(эффект `aegis`, не лежит в запасе).

**Применение** — `use_item {item, targetId?}`, в `usePhases` предмета и в его `modes`; не хватает в запасе / не та
фаза / не тот режим — молча игнор. Списывается 1 шт.

| Предмет | Когда | Действие |
|---|---|---|
| **Blink** | QUESTION, отвечающий (all, closest, керри сам) | Не через use_item: `submit_answer {answer, blink: true}` при уже отправленном ответе меняет ответ и тратит блинк. Всем `item_used` (если не в смоке). |
| **Gem** | QUESTION, all / closest; цель — другой отвечающий | Смотрящему — `gem_result {targetId, answer (текущий выбор или null), smoked}`. Всем — `item_used` без цели (если смотрящий не в смоке); цели — `item_used {onYou: true}`. Цель в смоке: `answer: null, smoked: true`. |
| **Manta** | QUESTION, all / керри сам; раз за раунд | Убирает случайный неверный вариант (из ещё не убранных): себе — `manta_result {optionIndex}`, в стейт — `removedOptions`; ответ убранным вариантом отклоняется. Всем `item_used`; у керри — с `optionIndex` (толпа видит). |
| **Smoke** | QUESTION, all / closest; раз за раунд | До конца раунда: другим твой `hasAnswered` = false, `player_answered` — только тебе; твои блинк / гем / манта не рассылаются; гем на тебя — `smoked`. Само применение видно всем (эффект `smoke`). |
| **Hex** | BETTING, all; цель — другой игрок; один бросок на бросающего и одна порча на цель за раунд | У цели в QUESTION только `HEX_SECONDS` (12 с): позже ответы и блинки не принимаются; по истечении цель считается «ответившей» (без ответа) для досрочного конца фазы. Цели — `hexTimeLeft` в её стейте. Всем `item_used {targetId}`, у цели эффект `hex`. |
| **BKB** | ANNOUNCE / BETTING, all / керри (толпа); раз за раунд | Если раунд для игрока в минусе — возврат `min(потеря, BKB_CAP)`, источник «BKB». Серия не сбивается. Эффект `bkb`. |
| **Aegis** | пассивный, один на игру | После расчёта раунда баланс < `AEGIS_THRESHOLD` → становится `AEGIS_RESTORE`, источник «Аегис», эффект снимается. |

## Конец вопроса

Все ответили — раунд считается не сразу, а через `LAST_ANSWER_GRACE_MS` (1 с); блинк в это окно перезапускает
отсчёт. «Все ответили» учитывает хекс: у цели после 12 с — как ответ.
