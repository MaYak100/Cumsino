- [ ] **Порог флага «шаг очень мелкий»:** 3% не подходит для цен (шаг 100 на 3725 нормален) — снизить для цен до 2% или считать по категории.

## 1. Новые категории

### Нечисловые механики
Вопросы «при каком условии», «найди ложный факт», «что фиксировано, а что рандом», «как
стакается», взаимодействия с BKB, диспелом, иллюзиями. Самая трудная для генерации категория:
в первой итерации подделки выходили бредом, который серьёзные игроки отсекают сразу.

- [ ] Расширить вход: примечания к способностям из локализации (английские, как описания), поля dotaconstants `dmg_type`, `bkbpierce`, `dispellable`, `target_type`.
- [ ] Собрать 10–15 эталонных вопросов (ручные вопросы пользователя + лучшие из старых: Magnetize, Cold Feet, Bone Chill, Chaos Knight, Culling Blade) и сформулировать по ним стиль до написания промпта.
- [ ] Обязательная проверка вторым проходом (как у талантов): подделка не должна быть правдой и не должна описывать поведение по умолчанию.
- [ ] Учесть урок талантов: без шаблонных подделок, без зубрёжки чисел.

### Внешние источники
- [ ] Популярность героев и предметов (относительная: «кого из четырёх играют чаще»).
- [ ] Винрейт героев и предметов — абсолютный (число, режим шага) и относительный (сравнение).
- [ ] Выбрать источник и проверить доступ из окружения: Dotabuff, OpenDota API, Stratz. Зафиксировать снимок с датой, как для данных игры.
- [ ] Комментарий после ответа с цифрами (как в старом `general_main`: «Storm Spirit: 22 314 540 игр…»).
- [ ] История патчей: `patchnotes.json` уже в снимке — «что поменяли в 7.41».

### Отложено
- [ ] Юмор в вариантах ответа (в старой базе был намеренно) — вернуться отдельно.
- [ ] Таланты «какого нет» (3 настоящих + 1 подделка): механических талантов у героя обычно меньше трёх.

## 2. Интеграция в игру

- [ ] **Единый формат вопроса банка:** `category`, `fact_id`, `level`, `question`, `unit`, `step`, `patch`, `answer` (подставлен из данных при сборке); для талантов — `options` с отметкой настоящего.
- [ ] **Сборка банка:** скрипт, который берёт финальные прогоны (`full1`, `costs2`, `talents-full`), выкидывает вопросы с флагами и пишет новые файлы в `scripts/data/generated/` вместо старых `*_main.json`.
- [ ] **Генерация вариантов по шагу в сервере** (перенос `options.py` в TypeScript): случайная позиция ответа по величине среди допустимых (варианты > 0), варианты ровно через шаг, отдельное перемешивание порядка показа, заново при каждом показе.
- [ ] Типы в `shared` (`Question`: `category`, `step`, `unit`), `loadQuestions.ts` — выбор по категориям вместо старых файлов, режим «ближе всех» берёт только `answer`.
- [ ] Отображение тем в анонсе: `displayTopic` из `call_as` / имени героя / предмета.
- [ ] Сценарии на странице `/dev` под новые категории.
- [ ] Убрать старые файлы и скрипты после переезда: `scripts/data/generated/*_main.json`, `abilities_mb.json`, `scripts/generate/gen_questions.py`, `improve_questions.py`, архивные `scripts/data/*.json` и скрипты сборки старой базы.
