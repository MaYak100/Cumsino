# Соотношения категорий

Прогон 400 игр по 21 раундов (all → kerri → closest), опознано друзей: 0. Собрано `npm run ratios --workspace=server` по `server/src/game/questions/categories.ts` и текущим банкам.

- **вес** — базовый (MC) и в «кто ближе», если отличается (`closest` в categories.ts);
- **MC / ближе** — доля от раундов своего типа (MC = all + kerri, «ближе всех» — closest);
- **за игру** — сколько вопросов подкатегории в среднем за игру;
- **шаблоны / карточки** — разных текстов и того, по чему идёт колода (у готовых вопросов это одно и то же; у статистики — герой вопроса или ответ, причём ответом считаются только те, кто может быть лидером четвёрки с отрывом, — у «Винрейта» это треть пула; у друзей — человек и срез: сколько карточек выпало за прогон);
- **круг, игр** — через сколько игр колода проходит круг (карточки / за игру); **1-й повтор** — в какой игре подкатегория впервые повторила вопрос (у статистики повтор — тот же ответ или герой вопроса).
