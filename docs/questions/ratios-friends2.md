# Соотношения категорий

Прогон 300 игр по 24 раундов (all → kerri → closest), опознано друзей: 2. Собрано `npm run ratios --workspace=server` по `server/src/game/questions/categories.ts` и текущим банкам.

- **MC / ближе** — доля от раундов своего типа (MC = all + kerri, «ближе всех» — closest);
- **за игру** — сколько вопросов подкатегории в среднем за игру;
- **шаблоны / карточки** — разных текстов и того, по чему идёт колода (у готовых вопросов это одно и то же; у статистики — герой вопроса или ответ, у друзей — человек и срез);
- **круг, игр** — через сколько игр колода проходит круг (карточки / за игру); **1-й повтор** — в какой игре подкатегория впервые повторила вопрос (у статистики повтор — тот же ответ или герой вопроса).
