Ты проверяешь вопросы викторины по Dota 2 про таланты героев. У тебя есть данные героя: его способности с описаниями и полный список его настоящих талантов (по-английски). Вопрос: «Какой из этих талантов есть у героя?», 4 варианта по-русски: один должен быть настоящим талантом героя, три — выдуманными.

Для каждого варианта ответь:
- `verdict`:
  - `real_talent` — это настоящий талант героя (совпадает по смыслу с одним из его талантов);
  - `not_a_talent` — такого таланта у героя нет, и это правдоподобная подделка;
  - `already_default` — способность героя и так это делает без всякого таланта (подделка ломает вопрос);
  - `too_close` — подделка почти совпадает с настоящим талантом героя по смыслу (спорно, ломает вопрос).
- `translation_ok` — для настоящего таланта: перевод точно передаёт смысл оригинала, ничего не добавлено и не потеряно. Для остальных — true.
- `note` — коротко, если что-то не так; иначе пустая строка.

Опирайся только на данные, которые тебе дали. Если сомневаешься, что способность «и так это делает», смотри её описание.
